# github-stats-card

Cached SVG for [Jiksi](https://github.com/Jiksi)'s profile README.

A GitHub Action refreshes `github-stats.svg`, `top-langs.svg` and `streak-stats.svg` every day using the GitHub API:

- [github-stats.svg](https://raw.githubusercontent.com/Jiksi/github-stats-card/main/github-stats.svg)
- [top-langs.svg](https://raw.githubusercontent.com/Jiksi/github-stats-card/main/top-langs.svg)
- [streak-stats.svg](https://raw.githubusercontent.com/Jiksi/github-stats-card/main/streak-stats.svg)

The profile README embeds the committed SVG from `raw.githubusercontent.com` so the card keeps rendering without relying on an external service.
