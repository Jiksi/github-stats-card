# github-stats-card

Cached SVG for [Jiksi](https://github.com/Jiksi)'s profile README.

A GitHub Action refreshes `dist/github-stats.svg` and `data/stats.json` every day using the GitHub API:

- [github-stats.svg](https://raw.githubusercontent.com/Jiksi/github-stats-card/main/dist/github-stats.svg)

The profile README embeds the committed SVG from `raw.githubusercontent.com` so the card keeps rendering without relying on an external service.
